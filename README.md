# ML Projects

Коллекция учебных лабораторных, пет-проектов и экспериментов по машинному обучению на Python.

## Оглавление

### Пет-проекты

| Проект | Кратко | Статус |
|---|---|---|
| [❤️ Сервис оценки риска ССЗ](projects/heart-disease-risk-service/) | Главный проект: модель CatBoost, API и веб-анкета для информационной оценки риска сердечно-сосудистых заболеваний. | Основной проект |
| [Предсказание цен на жильё](https://github.com/KolyaNG1/House-price-prediction) | Отдельный репозиторий с задачей прогнозирования стоимости недвижимости. | Внешний репозиторий |
| [«Титаник»: выживаемость пассажиров](https://github.com/KolyaNG1/ML-PET-projects-Titanik) | Отдельный репозиторий с учебным пет-проектом по бинарной классификации. | Внешний репозиторий |

### Учебные лабораторные

Папка для лабораторных работ будет пополняться по мере обучения: [labs/](labs/).

## Навигация

Каждый проект оформлен как самостоятельная папка: с постановкой задачи, данными, кодом обучения, результатами исследования и инструкцией по запуску.

> Репозитории содержат учебные проекты. В частности, модель оценки риска ССЗ не является медицинским изделием и не предназначена для постановки диагноза.
